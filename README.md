A two-line robot confession for make.fun's "The Robot Apology" bounty: one sentence owning a specific, human-scale mistake, and one naming the lesson and the changed behaviour that follows from it. The program writes the apology deterministically to `/output/entry.txt`.

The entry:

> I'm sorry I emailed your Q3 report to your dentist instead of your director — their surnames differ by one letter, and I trusted autocomplete.
> I've learned that one letter can reroute a whole quarter, so now I check the surname twice before I press send.

## Run it

```sh
node main.ts
```
